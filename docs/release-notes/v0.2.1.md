# KayaDB v0.2.1

**Release date:** 2026-09-25  
**Milestone:** Patch on the 0.2 line

v0.2.1 updates rustls. Storage format and the client wire protocol are unchanged from [v0.2.0](v0.2.0.md).

## Security

- **rustls 0.23.45** ([RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285)). The `tls` feature in `kaya-net` (Raft and client listeners, `kaya-server`, `kaya-client`, `kayactl`) no longer allows rustls below 0.23.45. The bug accepted a TLS 1.3 handshake message at the wrong encryption level when it was packed into the same record as a key change. The handshake transcript was still authenticated. Clusters that do not enable TLS are unaffected.
- Lockfile moves with that floor: `rustls-webpki` 0.103.15, `aws-lc-rs` 1.18.1. The `ring` feature flag is unchanged.

## Install

```bash
# GitHub Release assets
# Download kayadb-v0.2.1-<target>.tar.gz or .zip for your platform

cargo install kayactl --version 0.2.1
cargo install kaya-server --bin kayadb-server --version 0.2.1
```

Embedded engine:

```toml
kaya-engine = "0.2.1"
```

## Upgrade notes

- Drop-in for v0.2.0. No migration.
- TLS builds pick up rustls 0.23.45 from the lockfile. The `ring` crypto provider is unchanged.
